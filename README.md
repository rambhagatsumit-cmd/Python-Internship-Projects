# Python Internship Projects

This repository contains four Python projects developed as part of my Python internship.

## Projects

### 1. Connect Four
A two-player Connect Four game implemented in Python. It manages player turns, valid moves, board positions, winning conditions, and draw conditions.

### 2. Snake Game
An interactive Snake Game with keyboard controls, continuous movement, food collection, score tracking, and collision detection.

### 3. Digital Clock
A simple digital clock developed using Python Tkinter. It displays the current system time and updates automatically.

### 4. Tic Tac Toe
A two-player Tic Tac Toe game with a 3x3 board, alternating turns, valid move checking, winning-condition detection, and draw detection.
